<{/if}> <{if $step.type == 'code'}>

The code has the same variables as procedures: each element's value in a variable named after its handle, $entry_id, $form_id, $currentValues (the values before an update, as stored), $changedElements (the handles of the elements that changed), $newEntry, and the outputs of earlier steps, in $outputs and in variables of their own. $entry is the entry for getValue() and display(), the same as in derived values. Before an entry is saved, the variables always hold the values as stored, changing an element's variable changes the value that is saved, and return false; stops the save. At other times, what the code returns, or puts in $output, is this step's output.
