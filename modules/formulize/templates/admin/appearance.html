Appearance

Customize the colours, font, and logo of the end-user interface. Each theme has its own settings, so pick the theme you want to change below. Variations of each colour (hover states, soft backgrounds, muted text) are derived automatically, so the interface always stays coherent.

Each theme's settings are kept in the stylesheet generated for it, <{$adminPage.appearance_css}>. Delete that file to put this theme back to the defaults.
