{% comment %} The main menu, from _data/nav.yml. Six top-level items - the same six questions a stranger arrives with, in order: what is it, what could I build with it, what is the AI story, what does it cost, where are the docs, is this project alive. Videos are a format rather than a topic, so they are a child of Docs rather than a seventh top-level item - people looking for "the docs" count a tutorial video as documentation. The community links live in the footer. Every item also carries a dropdown of its most-wanted subpages, so a visitor can see what is inside a section and jump straight to a specific page instead of landing on a hub page and hunting from there. The dropdown is a shortcut past the top-level link, never a replacement for it - the link itself always goes to that section's own page. Dropdowns are CSS-only (:hover / :focus-within on li.has-dropdown), so they degrade gracefully and work for keyboard users tabbing through. On the mobile (checkbox) menu they render open inline instead of needing a second toggle - see the max-width: 1060px rules in formulize.css. {% endcomment %}
{% comment %} Everything - logo, menu, both buttons - sits inside one dark box, so the pattern behind the header runs around the whole thing rather than behind the wordmark and the menu labels. The two buttons stack vertically at the far right, after the menu; stacked, they take about the height of the wordmark instead of stretching the box wider. The checkbox stays immediately before
