{% comment %} Embeds one Formulize screen from formulize.net into a page here. Usage: {% include embedded-form.html sid="1" title="Get help with Formulize" height="900" %} Parameters: sid the screen id on the Formulize site. 1 = Help Request, 3 = Get your own Formulize system, 5 = Join the mailing list, 7 = Unsubscribe, 27 = Report a bug. It has to be the sid, not the screen's prettier rewrite address (get-help, get-hosting): those do not resolve when the request comes from another domain, which is exactly the case here. Copy the sid from the screen's settings page, which is also where the rest of this markup comes from. title the iframe's accessible name. Required - it is what a screen reader announces when it reaches the frame. height starting height in pixels, before the screen reports its real one. Pick something close to the finished form so the page does not jump. This is the code the screen's settings page generates, with three changes: no border:0 in the style attribute, because formulize.css gives the frame a border; fallback="message", so that a visitor whose browser will not let the form be submitted is told so, above the frame, without being sent off to formulize.net; and pass-params, below. IMPORTANT - submissions and the same-domain rule. site.forms_url currently points at formulize.net, which is a different domain from this site. Browsers that block third-party cookies will not let the form be submitted from inside the frame. The fix is an alias of the Formulize site on this domain (forms.formulize.org) - see docs/embedding_screens_setup. PLAN PRE-SELECTION - /pricing/ and /signup/'s plan cards link here as ?plan=level-1..4, and formulize-embed.js passes that on to the screen. See hosting_requests_which_plan on the Hosting Requests form (form 2), which has a small script element of its own that reads it back out of window.location.search inside the frame and pre-selects the matching radio button. Harmless no-op on a screen with no such element and on a page with no ?plan= param. GOOGLE ANALYTICS - the screen is on formulize.net, so the tag in the layout cannot see inside it. The screen reports what the visitor does as events on the iframe instead, and the script at the bottom turns those into Google Analytics events: form_start, form_step, form_error, form_abandon, form_submit, plus a key event for the screens listed in keyEvents. Field names only, never anything a visitor typed. See /documentation/embedding_screens/analytics/, which has the same script for other sites to copy - keep the two in step. {% endcomment %}
