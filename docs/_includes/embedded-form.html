{% comment %} Embeds one Formulize screen from formulize.net into a page here. Usage: {% include embedded-form.html sid="1" title="Get help with Formulize" height="900" %} Parameters: sid the screen id on the Formulize site. 1 = Help Request, 3 = Get your own Formulize system. It has to be the sid, not the screen's prettier rewrite address (get-help, get-hosting): those do not resolve when the request comes from another domain, which is exactly the case here. Copy the sid from the screen's settings page, which is also where the rest of this markup comes from. title the iframe's accessible name. Required - it is what a screen reader announces when it reaches the frame. height starting height in pixels, before the screen reports its real one. Pick something close to the finished form so the page does not jump. The script is emitted once per page however many screens the page embeds, which is what formulize-embed.js expects. assign is page-scoped in Jekyll's Liquid, so the flag survives from one include call to the next. IMPORTANT - submissions and the same-domain rule. site.forms_url currently points at formulize.net, which is a different domain from this site. Browsers will not send the Formulize session cookie into a frame across domains, so the form displays but saving fails. The fix is an alias of the Formulize site on this domain (forms.formulize.org) - see docs/embedding_screens_setup. Until that exists, the "open in its own window" link below the frame is the route that actually works, and the sessionUnavailable handler promotes it the moment the screen reports the problem. {% endcomment %}

Trouble with the form? Open it in its own window, or email info@formulize.org and we will pick it up from there.
