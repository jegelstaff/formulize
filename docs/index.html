Improvise. Organize. Customize.

Formulize is 100% configuration based, so the thing you build on Monday can be a different thing by Friday.

Improvise

  • Create any kind of database application
  • 1 form, 10 forms, 100 forms, no limits
  • Browse your data with flexible search, sorting and reporting
  • Import from, and export to Google Sheets, Excel…

Organize

  • Join your forms together into custom workflows
  • Control who can interact with which forms and which data
  • Publish customized, searchable reports to some or all of your users
  • Do it all with your mouse, no programming required

Customize

  • Extensible with custom form elements, events, templates…
  • An API for working under the hood, and connecting other tools
  • Runs on PHP and MySQL/MariaDB
  • Completely free, and fully open source (GPL-2.0)
