--- layout: null permalink: /news/entry/ sitemap: false --- News | Formulize {%- comment -%} News stories used to live at /news/entry/?id=N, rendered in the browser. They are now static pages at /news//, generated by _plugins/news_pages.rb, which also emits a /news/entry// redirect for every story. This page exists only to keep the old query-string links working: a static host cannot route on a query string, so the hop has to happen here, in the browser, forwarding to the path-style redirect which then lands on the story. Anything without a usable id goes to the news index. {%- endcomment -%}
